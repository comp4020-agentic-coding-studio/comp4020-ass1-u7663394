# Assignment 1 — How big is a million?

## What was the breakthrough that moved the work forward?

My breakthrough was finding a better way to show how numbers grow. At first, my idea was very simple: when the number gets bigger, I could make the number or the visual bigger in 2D. But after seeing the first version, I realised this did not really help people understand the scale.

Then I decided to use space to show each 10× increase. One point becomes a line, lines become a plane, and planes become a 3D cube. For larger numbers, the same idea continues in 3D space. This made the experience much clearer because users can actually see what happens when the quantity becomes ten times larger.

I also added checks to make sure each stage really contains ten times as many points as the previous one. This was useful because the main idea of the project became something I could actually test.

## What did this work change about who I want to be as a software developer?

This project made me pay more attention to what users actually see and experience. During development, some animations were technically correct, but they still felt wrong. For example, some transitions were too fast, and the larger stages became messy or slow. I learned that passing tests does not always mean the experience is good. I had to watch the animations, find problems, change the implementation, and test again. In the future, I want to be a developer who checks both the code and the real user experience.
